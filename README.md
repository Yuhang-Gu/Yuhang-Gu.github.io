# Yuhang Gu — Academic Homepage

Personal academic website for **Yuhang Gu**, an undergraduate student at Tianjin University of Science and Technology. The site presents research interests, publications, academic competitions, experience, and awards.

## Site Structure

| Path | Purpose |
|------|---------|
| `_data/profile.yml` | Personal info, bio, education, experience, awards, social links |
| `_data/display.yml` | Show/hide homepage sections |
| `_data/navigation.yml` | Navbar pages |
| `_data/authors.yml` | Publication author display settings |
| `_publications/YEAR/` | Add publication entries (Markdown) |
| `_news/` | Add news/announcements (Markdown) |
| `assets/images/covers/` | Cover images for publications |
| `assets/css/global.css` | Custom styles |

## Local Preview

```bash
bundle exec jekyll serve
```

Then open http://127.0.0.1:4000/
